# curated_val_50 — summary

**Validation subset for S2GO Stage-1 and Stage-2.** 50 scenes curated from the
canonical nuScenes paper-val (150 scenes) — a "miniature paper val" that
preserves class diversity for stable per-class IoU measurement.

Generated by [../../scripts/build_train_val_split.py](../../scripts/build_train_val_split.py),
same anchor + greedy submodular curator used for training (smaller K values
because the candidate pool is only 150).

## Why this val (and not just the full 150)?

Three options were considered:

| Option | Scenes | Trade-off |
|---|---:|---|
| (A) Stratified random of paper-val | ~50 | Distribution-match, but rare classes can be under-represented by chance |
| **(B) Class-balanced subset of paper-val** | **50** | **What's used here** — every class guaranteed ≥18 val scenes |
| (C) Full paper-val | 150 | Most representative; 3× slower eval |

Use (B) for dev-loop val (this folder), and (C) — the full 150 — for final
reportable numbers.

## Same val for both stages

S2GO Stage-1 and Stage-2 share the **SurroundOcc 16-class mIoU/IoU** evaluation
protocol, so this single val set works for both. No separate Stage-1 vs Stage-2
val needed.

## To regenerate

Same script as train; both are produced in one call:

```bash
python scripts/build_train_val_split.py \
  --scene-csv dataset_stats/data/scene_stats.csv \
  --class-csv dataset_stats/data/class_composition_per_scene.csv \
  --out-train dataset_stats/curated_train_270 \
  --out-val   dataset_stats/curated_val_50 \
  --train-budget 270 --val-budget 50
```
